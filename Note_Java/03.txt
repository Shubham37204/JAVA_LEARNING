================================================================
How one java class method can access another java class method	(called as dependency)
==================================================================

1) By Inheritence or By Extending Properties (IS-A)

2) By Composition or By creating Object (HAS-A)	

=============
Conclusion
=============
=> if a class is dependent(target) on another class(dependent) then it is called Dependenciy

=> With IS-A & HAS-A relation our classes are tightly coupled.

=> Developing classs with tighlty coupling not recommended.

=> Always we need to develop our classes with loosely coupling.

=> To develop classes with loosely coupling we will use Spring Core module.

=> Tight coupling makes an application rigid, difficult to modify, test, and maintain.

=============
Spring Core
==============

-> It is base module in spring framework

-> Core module providing fundamental concepts of spring

		1) IOC container (IOC)
		2) Dependency Injection (DI)
		4) Autowiring 

=>These help us manage objects and dependencies, reducing tight coupling and making applications easier to maintain, test, and modify.

=> By  using spring core concepts we can develop classs with loosely coupling.

=> If we want our classes to be managed by IOC then we need to develop our classes with some rules.

=========================
Strategy Design Pattern
=========================

1) Favour composition over inheritence

2) Code with Interfaces instead of implementation classes

3) Code should be open for extension and closed for modification

Eg1:(lossing coupling): 

interface Engine{public int start();}

public class PetrolEng implements Engine{
	public int start(){sout("")}
}

public class DiesealEng implements Engine{
	public int start(){sout("")}
}

public class car{
	//instanced variable
	private Enginr eng;

	//Constructor
	public car(Engine eng){
		this.eng=eng;
	}

	//setter Method
	public void setEng(Engine eng){
		this.eng=eng;
	}

	public void drive(){
		int status = eng.start();
		sout("")
	}
}

//in main methods(without any constructor and no injection)
//when we do this then engine eng get default values 
ie null and and hence on calling c.drive we will get 
null pointer exception 
Car c = new car();
c.drive()

========================
Constructor Injection
========================

=> Inject one class object into another class obj using constructor.

	Ex : Car c = new Car(new PetrolEng());

========================
setter Injection
========================

=> Injecting one class object into another class object using setter method 

		Ex:   Car c = new Car();
			 c.setEng(new DieselEng());


Q) If we perform both CI & SI then what will happen ?

Ans) CI will happen first at the time of obj creation

Afte CI, SI will happenSI will override CI

So the final value will be SI injected value/obj.


=====================
Dependency Injection
=====================

=> The process of injecting dependent object into target object is called as dependency injection.

		Car is dependent on Engine

		Controller is dependent on Service

		Service is dependent on DAO

=> We can perform Dependency Injection in 3 ways

		1) Constructor Injection
		2) Setter Injection
		3) Field Injection	
		eg for field Injection:
		c.eng= new PetrolEngine();
